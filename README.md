# Личная CRM

Записная книжка людей, которых вы знаете лично: кто это, откуда знакомы, телефон, почта и заметки после разговоров.

Идея и критерии успеха — в [`specs/01-продуктовая-идея.md`](specs/01-продуктовая-идея.md).

## Что умеет

- **Список контактов** — на главной странице все контакты по алфавиту и их общее число.
- **Поиск по имени** — ищет на лету, пока вы печатаете. Регистр, порядок слов и «ё/е» не важны: «семен иванов» найдёт «Иванов Семён».
- **Добавление контакта** — после сохранения контакт подсвечивается в списке.
- **Карточка контакта** — все данные и заметки, новые сверху. Заметка дописывается прямо в карточке.
- **Редактирование контакта** — кнопка «Изменить» в карточке.

Данные хранятся в PostgreSQL. Браузер к базе не обращается: всё читает и записывает сервер приложения. Поэтому по тому же адресу из любого браузера видно одно и то же.

## Что нужно установить

- [Node.js](https://nodejs.org/) 20.9 или новее
- [pnpm](https://pnpm.io/)
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) — для базы данных

## Первый запуск

1. Создайте файл с настройками: скопируйте `.env.example` в `.env` и заполните значения.
   Приложение берёт подключение к базе из `DATABASE_URL`, а если её нет — собирает его из `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB` и `POSTGRES_PORT` (те же значения, что использует Docker).
2. Запустите базу:
   ```
   docker compose up -d
   ```
3. Установите зависимости:
   ```
   pnpm install
   ```
4. Создайте таблицы:
   ```
   pnpm db:migrate
   ```
5. (Необязательно) Заполните базу тестовыми данными — 1000 контактов с заметками:
   ```
   pnpm db:seed
   ```
   Скрипт работает только с пустой базой: если контакты уже есть, он ничего не сделает.
6. Запустите приложение:
   ```
   pnpm dev
   ```
   и откройте http://localhost:3000

## Команды

| Команда | Что делает |
| --- | --- |
| `pnpm dev` | Запуск в режиме разработки: изменения в коде видны сразу |
| `pnpm build` и `pnpm start` | Сборка и запуск в «боевом» режиме — работает быстрее |
| `pnpm db:migrate` | Применить миграции: создать или обновить таблицы |
| `pnpm db:generate` | Создать новую миграцию после изменения схемы в `src/db/schema.ts` |
| `pnpm db:seed` | Заполнить пустую базу тестовыми контактами (`pnpm db:seed 200` — другое количество) |
| `pnpm lint`, `pnpm typecheck` | Проверить код |

## Как устроен проект

```
src/
  app/                  страницы
    page.tsx            список контактов с поиском
    contacts/new/       добавление контакта
    contacts/[id]/      карточка контакта с заметками
    contacts/[id]/edit/ редактирование контакта
    actions.ts          сохранение данных (выполняется на сервере)
  components/           части интерфейса; ui/ — компоненты shadcn/ui
  db/                   схема таблиц и подключение к базе
  lib/                  запросы к базе, проверка введённых данных, форматирование
drizzle/                миграции базы
scripts/seed.ts         генератор тестовых данных
```
